# 🧠 Deep Learning with PyTorch

A hands-on collection of **PyTorch programs** exploring neural networks, regression, optimization, and sequence prediction.

### 🚀 What's Inside?

* 📈 **Neural Network Regression**
* 🎯 **Loss Function Comparison** — MSE, L1, Huber & SmoothL1
* ⚡ **Optimizer Comparison** — SGD, Adam, RMSprop & Adagrad
* 🏠 **House Price Prediction** — Feed-Forward Neural Network
* 🌧️ **Rainfall Prediction** — RNN
* 📊 **Stock Price Prediction** — LSTM

### 🛠️ Tech Stack

**Python • PyTorch • NumPy • ANN • RNN • LSTM**

### ⚙️ Quick Start

```bash
git clone https://github.com/AchitaParmar/Deep-Learning-with-PyTorch.git
cd Deep-Learning-with-PyTorch
pip install torch numpy
```

Run any program:

```bash
python houseprediction.py
```
